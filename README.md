# Trabalho de Conclusão de Curso

Materiais reunidos para o TCC sobre inteligência artificial aplicada à gestão de projetos.

## Estrutura

- `TCC_Codigos/`: código-fonte, dados, exemplos e documentação do sistema.
- `Planejamento/`: materiais de planejamento e explicações do projeto.
- `ProjetoTCCv01.ipynb`: notebook de trabalho.
- Documentos e arquivos ZIP na raiz: propostas, versões acadêmicas e pacotes do projeto.

Arquivos temporários gerados pelo Python e pelo pytest são ignorados por `.gitignore`.
