# Validação funcional do protocolo V2

68 testes aprovados. A demonstração abrange 15 exemplos autorais de desenvolvimento,
com prazo e custo nas duas condições: 60 perguntas. As referências foram registradas
separadamente do motor, mas ainda não têm revisão independente de domínio.

As respostas deste diretório são produzidas pelo motor de regras para testar o
contrato. **Não são respostas de uma IA e não são resultados empíricos do TCC.**
Nenhuma nova chamada à API foi feita nesta implementação.

O comando também exporta entradas sem gabarito para coleta posterior de previsões.
Os dados, prompts, grafo e resultados do experimento legado não foram substituídos.

Veja ../../docs/protocolo_evidencias_v2.md para critérios e limites.
